# Tankstelle in der Nähe

Free German static site for drivers: fuel-cost calculator, trip planner, L/100 km consumption calculator, EV vs petrol cost comparison and Super E10 vs Super savings calculator, plus a German fuel reference table and six practical guides about finding cheap fuel, saving fuel and staying safe at petrol stations.

Built with pure HTML, CSS and vanilla JavaScript. No external libraries, no webfonts, no tracking. Deploy the files as-is to GitHub Pages.
